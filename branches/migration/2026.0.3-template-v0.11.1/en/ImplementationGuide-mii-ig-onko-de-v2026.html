Where the versions come from. Every package in the table is pinned directly in sushi-config.yaml (dependencies:) — including hl7.terminology.r4 (THO) and hl7.fhir.uv.extensions.r4, and those two deliberately so: the IG Publisher's automatic-packages rule consults only this guide's own dependency list, so without a direct pin every build would silently inject the latest THO/extensions release — a version pinned by the MII meta package alone cannot control the build (verified in the publisher source at the pinned release). A weekly check warns when these two pins drift from what the pinned meta package ships, and the exact versions a concrete build used are recorded in its qa-versions.json output.
