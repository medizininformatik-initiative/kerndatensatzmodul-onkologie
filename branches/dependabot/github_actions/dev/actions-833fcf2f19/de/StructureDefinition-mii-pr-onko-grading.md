Histologie: Tumor Grading. Gibt den Differenzierungsgrad des Tumors entsprechend der aktuellen TNM-Auflage an. 

Dieses Profil beschreibt eine Histologie-Grading im Rahmen in der Onkologie. Dabei wird insbesondere die morphologische Dedifferenzierung des Gewebes bewertet.
