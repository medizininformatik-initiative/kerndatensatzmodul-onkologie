## {{page-title}}

The oncology extension module is based on the oncological basic dataset (oBDS) in the version published in the Federal Gazette 2021. The contents are publicly available.

* Website of the oBDS with all relevant data fields, descriptions, and response options: https://basisdatensatz.de/basisdatensatz
* The oBDS: XML schema in version 3.03; here in particular the information on hierarchy, field IDs, and data validation
    * current version: https://basisdatensatz.de/xml/oBDS_v3.0.3.xsd
    * older versions available at https://basisdatensatz.de/xml/

</br> 

* Confluence-based implementation guide of the cancer registry platform §65c https://plattform65c.atlassian.net/wiki/spaces/UMK/overview, in particular:
    * https://plattform65c.atlassian.net/wiki/spaces/UMK/pages/15532576/Datenmodell for the general data model
    * https://plattform65c.atlassian.net/wiki/spaces/UMK/pages/15532143/Meldungsinhalte and all subpages for detailed views and data model diagrams of the individual report contents

There are older preliminary works for mapping the oBDS as an information model on the ART-DECOR platform, which currently do not fully reflect the current status. These can be accessed [here](https://art-decor.org/art-decor/decor-datasets--mide-?id=2.16.840.1.113883.3.1937.777.24.1.1&effectiveDate=2018-06-05T12%3A44%3A12&conceptId=2.16.840.1.113883.3.1937.777.24.2.62&conceptEffectiveDate=2018-06-06T06%3A13%3A32).
