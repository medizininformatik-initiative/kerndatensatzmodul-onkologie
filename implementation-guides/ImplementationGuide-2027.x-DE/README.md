# ImplementationGuide 2027.x-DE — Staging-Korpus

Dieser Ordner ist der **Arbeitsstand des v2027-Implementierungsleitfadens**.
Er wird — anders als die 2025er/2026er Ordner — **nicht** als Simplifier-Guide
veröffentlicht: Der v2027-IG entsteht durch den Umzug auf den **HL7 IG Publisher**
(MII-KDS-Modul-Template, Migration per Skill `mii-ig-migration`).

Regeln bis zur Migration:

- **Alle** IG-Seitenänderungen für v2027 gehören hierher.
- `ImplementationGuide-2026.x-DE/` ist auf dem Stand der Veröffentlichung
  v2026.0.3 **eingefroren** — dort nichts mehr ändern.
- Die Release Notes v2027 leben in
  `MIIIGModulOnkologie/Release-Notes.page.md` in diesem Ordner.
- Bei der Migration dient dieser Ordner als Transfer-Input (Harvest der
  Narrative in die IG-Publisher-Seitenstruktur); danach wird er ersetzt.
